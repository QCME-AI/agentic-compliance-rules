# Changelog

## [0.1.0] - 2026-02-09

### Added
- Initial rule schema (`schemas/rule.schema.json`) and pack schema (`schemas/rule-pack.schema.json`)
- FTC rule pack: 91 rules covering endorsements, claims, disclosures, and consumer protection
- HIPAA rule pack: 17 rules covering PHI protection, consent, and privacy notices
- GDPR rule pack: 17 rules covering consent, privacy policies, data rights, and transfers
- Validation tools: schema validation, fixture checks, licensing checks, index builder
- Claude skill for validating marketing copy (`skills/validate-copy/`)
- CI workflows for validation and release
